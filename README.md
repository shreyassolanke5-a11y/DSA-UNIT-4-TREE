# DSA-UNIT-4-TREE
Music Playlist Application Using BST and Doubly Linked List

## Project Description

This project implements a Music Playlist Application in C++ using a Binary Search Tree (BST) and converts the BST into a sorted Doubly Linked List (DLL).

Each song is stored with a unique Song ID and Song Name. The Song ID is used as the key for inserting songs into the BST. The application sorts songs by their IDs using inorder traversal and converts the BST into a doubly linked list.

# Objectives

- To implement a Binary Search Tree in C++.
- To insert songs using Song IDs as keys.
- To display songs in ascending order of their IDs.
- To convert a BST into a sorted Doubly Linked List.
- To understand tree traversal and linked-list operations.

# Technologies Used

- Programming Language: C++
- Data Structures: Binary Search Tree, Doubly Linked List
- Compiler: GCC / G++ or any standard C++ compiler

# Features

1. Add a song to the playlist.
2. Display songs in sorted order using inorder traversal.
3. Convert the BST into a Doubly Linked List.
4. Display the sorted playlist.
5. Exit the application.
